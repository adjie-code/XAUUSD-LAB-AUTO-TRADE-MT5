# Generated EA

Folder ini berisi EA `.mq5` hasil **Strategy Lab → Strategy Tester → Generate EA**.

- EA di sini **bukan** EA aktif dan tidak otomatis dipasang ke chart.
- Setiap EA memakai magic sendiri dan hanya mengelola posisinya sendiri.
- Wajib compile dan validasi ulang di MT5 (Windows/portable) sebelum demo.
- EA hasil generator adalah draft; backtest Python bukan jaminan hasil live.
